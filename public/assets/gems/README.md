# Direktori Ikon Permata Kustom Splendor

Jika ingin mengganti ikon permata bawaan (SVG vector) dengan file PNG kustom:
Taruh file PNG transparan (disarankan ukuran 64x64 atau 128x128 piksel) di folder ini (`public/assets/gems/`):

- `diamond.png` (Permata Berlian Putih)
- `sapphire.png` (Permata Safir Biru)
- `emerald.png` (Permata Zamrud Hijau)
- `ruby.png` (Permata Rubi Merah)
- `onyx.png` (Permata Oniks Hitam)
- `gold.png` (Koin Emas / Joker)

Jika file tidak ada, sistem otomatis memakai ikon faceted gem vector SVG beresolusi tinggi.
